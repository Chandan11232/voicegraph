# Voicegraph: Demo Video (2 min, simple)

🎙️ = you say it · 🗣️ = dictate it with Wispr Flow (hold Fn, speak, let go)

**Before recording:** open https://voicegraph-mocha.vercel.app/app?sample=1 and do one test dictation.

---

### 1. Intro (15 sec)
Show the home page.

🎙️ "Every project needs an architecture diagram, but drawing one takes forever. Voicegraph lets you just say it. And I built it entirely by voice, with Wispr Flow."

Click **Open workspace**.

---

### 2. How it works (30 sec)
🗣️ "New diagram called How it works"

🗣️ "I speak into Wispr Flow, and it types into the Voicegraph app. The app sends my command to a Vercel function, which asks an AI model on Groq and sends the new diagram back."

🎙️ "That's the whole architecture. I talk, Wispr types, and an AI on Groq draws the diagram in about a second."

---

### 3. Edit by voice (30 sec)
🗣️ "Open the online store diagram"

🗣️ "Add a Redis cache in front of Orders DB"

🗣️ "Select all databases" → 🗣️ "Make these red"

🎙️ "I can also drag any box by hand."  *(drag one box)*

---

### 4. Review and fix (30 sec)
🗣️ "Review my architecture"

🎙️ "It finds weak spots, like the storefront talking straight to the database."

🗣️ "Fix the first one"

🎙️ "And it fixes them for me."

---

### 5. Ship it (15 sec)
🗣️ "Write the README section"

🗣️ "Copy for README"

🎙️ "It writes the docs, and the diagram goes straight into my GitHub README."

---

### 6. Close (10 sec)
Show your Wispr Flow Insights card.

🎙️ "Voicegraph. Say the system, shape it by hand."
